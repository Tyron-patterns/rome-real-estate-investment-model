# Source Files

This folder contains the reusable Python modules used throughout the real estate investment analysis project.

- `omi_scraper.py`  
  Contains the functions/classes used to collect and process OMI real estate market data.

- `real_listing.py`  
  Handles the collection and structuring of real estate listing dataset used for market comparison.

- `functions.py`  
  Contains general helper functions used across the project for data processing, analysis, and calculations.

- `areas_dictionaries.py`  
  Stores dictionaries and reference mappings for Rome areas, neighborhoods, and related geographic information.
